    LOCAL SETUP

    Connection & Chrome extension

    The companion sends selected record and procedure excerpts to your MDT-GPT endpoint.

    1

    Connect GPT-5.6-terra

    Use your MDT-GPT Provider API token. It stays in memory while the companion is running.

    Leave blank to keep the token already entered.
    Verify this ID is enabled under MDT-GPT → OpenAI → Models. The app never switches models automatically.

    MDT-GPT Production — fixed for this app.

    The extension can pass fresh report files from this folder to the companion.

    Endpoint and local files

    Procedures, extracted records and generated reports are stored on this computer. Treat this folder as complaint data.

    2

    Add the GCH button

    1. Download the extension.

      Unzip it into a permanent folder on this computer.

    2. Load it in Chrome.

      Open chrome://extensions, enable Developer mode if your organization permits it, then choose Load unpacked and select the extracted folder.

    3. Install the background helper.

      Run Install-Windows.cmd from the same package. Chrome starts it automatically. Enter the Production API token in the GCH panel; no pairing code is needed.

    4. Save the GCH record, then check it.

      The button selects Print → Detailed Event Report (PESR fallback) and watches for the download. If a PDF viewer opens, use its Download button. You can also choose the exported report manually.

    GCH menu automation must be verified in your environment. The extension stops when it cannot identify a unique action.
